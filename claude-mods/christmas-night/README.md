# Christmas Night: a Claude Code backdrop

An animated backdrop for the Claude desktop and mobile apps. It shows a snowy log cabin with glowing windows and chimney smoke, a reindeer that nods its head, and a lit tree with presents. Santa's sleigh flies past the full moon about once every 48 seconds, the stars twinkle, and three layers of snow fall. The theme also sets dark midnight-blue colors for the app.

Install it by copying this folder into a plugin directory, or start Claude Code with `claude --plugin-dir ./claude-mods/christmas-night`.

The terminal does not draw backdrops. The scene shows only in the desktop and mobile apps.
